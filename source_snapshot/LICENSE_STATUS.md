# License status of this local review candidate

This candidate has not been publicly released. No blanket MIT license is asserted.
The authors must confirm ownership and a suitable license for the archived project
code before repository publication. Third-party packages retain their own licenses.

OpenNeuro ds002778 version 1.0.5 declares CC0 in its official metadata:
https://raw.githubusercontent.com/OpenNeuroDatasets/ds002778/1.0.5/dataset_description.json

The included data are the unchanged stored processed input and split definitions
used in the newly completed ds002778 runs, not a new raw preprocessing pipeline.
The metadata contain source pseudonyms and diagnosis/probability information; the
candidate requires final author/privacy review even where CC0 redistribution is
available. No claim of irreversible anonymization or clinical approval is made.

The unrelated raw EEG archives, clinical age/sex files, credentials, and machine
operation logs are not included. Original internal provenance remains outside the
payload. Public citation and attribution should refer to the original dataset and
its primary study as well as the eventual paper/repository version.
