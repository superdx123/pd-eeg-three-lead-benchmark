# Execution and conversion environments

New ds002778 S/W training and native independent prediction checks used Python
3.10.8, PyTorch 2.5.1+cu121, CUDA 12.1, cuDNN 90100, NumPy 2.2.6, pandas 2.3.3,
scikit-learn 1.7.2 and NVIDIA GeForce RTX 3080 Ti. Protocol JSON files are copied
unchanged; their hard version gates must not be relaxed to pretend exact replay.

The candidate's weights were reserialized on CPU only using PyTorch 2.10.0+cpu.
Every network tensor was checked bitwise against its original; environment,
dataset indices and other nonessential checkpoint metadata were removed. This is
not a new forward prediction check on another runtime. Original 2.5.1 native
replay receipts remain in the internal research archive.

Archival training runners are in `experiments/S/scripts/run_fold.py` and
`experiments/W/scripts/run_fold.py`. They do not auto-run on import. Running them
requires the original pinned CUDA environment and explicit seed/fold arguments;
each rejects existing task directories. This preparation did not run them.

Original independent validators apply to the full checkpoints generated by those
runners, not directly to the reduced public-candidate model files in `weights/`.
The new `FROZEN.json` files bind packaging-only inputs and exact preserved code;
they are not a pre-registration or recovery of old execution versions.
